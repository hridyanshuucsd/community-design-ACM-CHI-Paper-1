# Community Design, ACM CHI Paper 1

This repo holds the working materials for a CHI paper proposal about a multiuser, voice first, AI assisted 3D building design tool for community groups, built on top of the open source Pascal editor. Here is what each file is for, in plain terms.

- **proposal.md**: The actual proposal. Written as a letter, in my own voice, to explain why I want to build this, what the tool does, why it is a real research contribution and not just an app, how the study is designed, and what I am asking my collaborators for. Start here.

- **PAPER_STRUCTURE.md**: A full outline of what the eventual CHI paper would look like, section by section (introduction, related work, system, study, results, and so on). For each part of the study, it also spells out what a successful result would actually look like and what a failed or null result would look like, so the plan is honest about what could go wrong, not just what could go right.

- **research/related-work-synthesis.md**: A written summary of the other papers and tools closest to this idea (civic design tools, feedback and creativity research, interface research, voice interface research), what each one does well, what it misses, and how our tool is different from each of them.

- **research/chi-uist-rigor-checklist.md**: A checklist built from studying well regarded CHI and UIST papers, used to check our own study plan against the same bar those papers were held to (sample size, study design, honesty about limitations, and so on).

- **research/open-source-landscape.md**: A list of real, existing open source tools and data sources that could be used alongside Pascal instead of building everything from scratch, covering multiuser syncing, local building rule data, voice and speech tools, and building file (BIM) compatibility.

- **research/raw-literature-notes.md**: The detailed, unedited research notes behind related-work-synthesis.md, one entry per paper. This is the backup material, useful if I need to check a specific claim or detail later, not something that needs to be read start to finish.
